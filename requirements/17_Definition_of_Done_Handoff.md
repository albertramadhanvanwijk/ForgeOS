# 17 --- Definition of Done & Handoff

Product: scope/requirements/acceptance criteria defined; material
changes documented. Engineering: agreed interfaces followed; no
placeholder claimed real; error/permission paths handled;
migrations/config changes documented. Testing: relevant tests actually
executed and inspected; regression risks assessed; skipped tests
justified. Security: permissions checked; secrets protected; isolation
appropriate; approvals cannot be bypassed; sensitive actions audited.
UI: connected to real backend; status reflects actual state; error/empty
states; design system; relevant visual checks. Reliability: critical
state persists; retries bounded; cancellation/recovery evaluated;
rollback claims supported. Platform Builder: impact documented;
versioned valid change set; isolated implementation; validation run;
approvals follow policy; graph updated only after verified release.
Handoff: summary, changed files, test commands/results, known
limitations, updated traceability, next steps.
